# Fleet — capability map

Every capability in scope, what good looks like, what Ever Works has today, the verdict, and the
epic that owns it. Verdicts: **adopt** (new to Ever Works), **extend** (exists, grows), **feed**
(exists; this program only feeds it), **keep** (exists, unchanged), **defer** (worth it, not in
this program), **refuse** (deliberately not).

"Today" cites [EXISTING-SUBSTRATE.md](./EXISTING-SUBSTRATE.md) sections (§1 node runtime, §2
platform fleet and live view, §3 sessions, §4 schedules, §5 Tasks and nouns, §6 plugins, §7
sidebar, §8 contracts, §9 known gaps).
