## 0. Orientation — three facts to hold before reading an epic

1. **"Computer" is UI copy for a `FleetNode`.** There is one machine entity
   (`packages/agent/src/entities/fleet-node.entity.ts:L96` → table `fleet_nodes`), with kinds
   `desktop-node · node · k8s` (`packages/contracts/src/fleet/fleet-node.types.ts:L46-49`). `k8s` rows
   are merged live from the user's own configured cluster and never stored or leased
   (`packages/agent/src/fleet/fleet.service.ts:L321-325`, `L955-960`; `docs/features/fleet.md:L22-28`).
2. **A machine gives three separate consents** — enrol (heartbeat only), `--work` (lease and execute
   jobs), `--attend` (allow live viewing). They are independent flags on one process
   (`apps/node/src/core/runtime.ts:L476-480`, `L371-378`). There is no fourth consent today (§1.14).
3. **Everything a node does is outbound.** HTTPS polling for registry and work, one outbound WebSocket
   per live view (`apps/node/README.md:L195-196`; `apps/node/src/core/screen/node-leg.ts:L12-35`).
   Nothing listens on a machine; the platform never holds a machine credential.

### 1.8 Model usage limits on the node (new, 2026-10-17)

`executors/agent-task.ts:L940-969` recognises a CLI's out-of-quota sentence
(`recognizeModelUsageLimit`, `L2334-2347`; a timeout is never a limit), reports
`failureKind: 'model_usage_limit'` + `retryAfter` instead of a failure, and the worker loop throttles
**that CLI** until the reset (`core/worker-loop.ts:L107` `MODEL_THROTTLE_SYNC_GRACE_MS`;
`runtime.ts:L662-664` — a node whose only CLI is out of quota stops leasing `agent-task`). The heartbeat
