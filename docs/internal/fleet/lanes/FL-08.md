## Decisions

1. **The service lives in the API, not the agent package.** Plan §5 put `FleetLogsService` in
   `packages/agent/src/fleet/logs/`, but the node link (`FleetLinkService`, the viewer minter and gateway) is
   API-side (`apps/api/src/fleet-link/`), and the agent package must not import the API. The service, the
   controller, the viewer observer and the flag guard are `apps/api/src/fleet/logs/`; the Agent tool factory
   stays in the agent package and reaches the read through a port (`FleetLogsReaderPort`) the API can bind.
2. **Nothing streams until the reader asks** (plan §6 step 2): the channel opens, then the browser sends
   `logs.follow { on: true, lines }` after `viewer.ready`, and the one-shot read sends `logs.read { lines }`.
   No race between `channel.ready` and the first `DATA`.
3. **Source ids are self-describing** (`file:/var/log/syslog`, not `file:<sha1>`): the node needs the path to
   open it anyway and re-validates it against its roots on every open; a typed path is then just another id.
   Ids are bounded at 400 characters so a viewer token's params stay inside FL-02's 512-byte bound.
4. **Redaction marker** is the shared scanner's own (`[redacted secret]`), not a second spelling.
5. **Audit rows on the viewer path are written when the batch completes** (`logs.initial-done`), so they carry
   the real line and redaction counts (FR-27): the viewer gateway gained one additive optional observer hook
   (`nodeMessage`) that sees the node's JSON control messages on the channel — never a `DATA` payload.
6. **Pause is the viewer's** (FR-15 counts arrivals while paused): the browser keeps receiving and holds what
   arrives; the node still implements `logs.pause` / `logs.resume` (≤ 1 MiB held, oldest dropped and counted)
   for a reader that wants to save the link.
7. **Root-only files and the Security log without elevation refuse `unsupported_on_node`** with the hint the
   spec writes (U6, U7) — `permission_denied` is the platform audience's code.
8. **Per-viewer channel cap (8) is per API replica**, like FL-04's viewer cap: a courtesy limit that keeps one
   person inside the link's 64-channel budget, not a security boundary.

## Questions for the owner

1. **Windows standard log directories** (spec §8b): built the default — on Windows only the allowed roots (and
   `--files-root` folders) are listed; `C:\Windows\Logs` is not.
2. **`--files-root <dir>` is new on `ever-works-node start`** (R-18 names it; FL-08 lands first, R-39). It is
   repeatable and process-scoped like `--manage`; FL-11 reuses it.
